# sales_report_prompts
DIO Challenger for MS AI for Tech
# Características
- A empresa foca apenas em fabricação de consoles, deixando a distribuição e venda para terceiros
- Os produtos são vendidos globalmente

# Objetivos
- [ ] Consolidar todas as bases de terceiros para realizar uma análise 
- [ ] Transformar dados de vendas em informações relevantes para o fabricante
- [ ] Quais são os produtos mais populares em cada pais
- [ ] Como otimizar o processo de transporte e logística até o momento da venda

Prompts para Gerar Insights de Relatórios de Venda

Tendências de Vendas Mensais/Trimestrais:
. Quais foram os principais produtos vendidos nos últimos três meses?
. Houve variações sazonais significativas nas vendas? Se sim, quais foram as causas possíveis?
. Qual foi o impacto das promoções nas vendas mensais?

Desempenho por País:
. Quais países apresentaram o maior crescimento nas vendas?
. Algum país específico está abaixo da média de desempenho? Se sim, por que?

Análise de Clientes:
. Existe um padrão específico de compra entre diferentes faixas etárias?

Previsão de Vendas:
. Com base nos dados atuais, qual é a previsão de vendas para o próximo trimestre?
